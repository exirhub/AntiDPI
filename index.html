A few useful details.

What is included in the download?

A compiled AntiDPI runtime, browser assets and an installation script, bundled into one .run file. Original Python application source, bytecode and Git credentials are excluded. System dependencies require an internet connection during installation.

Can I update my existing installation?

Use the Update existing command. Accounts, configuration, certificates and traffic history are preserved. The installer keeps the existing haproxy-configer service names for compatibility. Take an encrypted backup from the panel before updating.

Which ports do I need?

The default management port is TCP 9443, with the main TCP listener on 8443. Port 80 is used for optional HTTP-01 certificate validation. Open the required ports in your provider firewall. Use --no-acme-http if port 80 is already occupied.

What does “compiled” protect?

The original backend source is not shipped. Native compilation raises the effort required to reverse engineer the application; it is not an absolute barrier against a server administrator. Browser code and HAProxy configuration remain inspectable by someone with sufficient access.
